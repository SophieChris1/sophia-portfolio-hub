# Image folder guide

- `profile/` – legacy reserved directory. The homepage displays Sophia's supplied portrait from `src/assets/sophie.jpg` without face edits. `src/assets/research-workspace.jpg` is retained but no longer displayed on the homepage.
- `projects/` – existing project thumbnails: `research.jpg`, `portfolio.jpg`, `data.jpg`, `writing.jpg`. Preserve these images unless Sophia requests a replacement. Content paths are maintained in `src/lib/portfolio-data.ts`.
- `certificates/` – legacy reserved directory; no certificate images are displayed. Courses & Training uses existing icon artwork only.

The current project images are illustrations, not real photos from Sophia's work.
