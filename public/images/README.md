# Image folder guide

- `profile/` – reserved for Sophia's real photo. The current opening image is an illustrative research workspace; a portrait will be added when supplied.
- `projects/` – project thumbnails. Replace `research.jpg`, `portfolio.jpg`, `data.jpg`, `writing.jpg` with your own images (keep the same names, or update the `image` paths in the `projects` list).
- `certificates/` – add certificate scans here and set the `image` field in the `certificates` list.

The current project images are illustrations, not real photos from Sophia's work.
